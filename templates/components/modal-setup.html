{# Setup Modal Component #}
Client Setup

To launch streams directly from this dashboard, you need to install the Moonlight protocol handler on this computer.

Download Handler

Download and run the registry file to enable moonlight:// URLs.

Download moonlight-handler.reg
Install

Double-click the downloaded .reg file and confirm the import.

Test Handler

Click below to test if the handler is working. Moonlight should open.

Pairing Moonlight Clients

Each device running Moonlight must be paired with the host PC:

  1. Open Moonlight on your client device (phone, tablet, PC, etc.)
  2. Your host PC should appear automatically. Tap/click on it.
  3. Moonlight will display a 4-digit PIN
  4. Open the Apollo/Sunshine Web UI on your host PC (gear icon on cards)
  5. Go to PIN tab and enter the code
  6. The client is now paired and can stream from that host
Apollo Credentials

To detect apps from Apollo/Sunshine servers, add your credentials to config.json. All servers must share the same username/password. 

"apollo_user": "your_username",
"apollo_password": "your_password"
