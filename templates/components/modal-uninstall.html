{# Uninstall Modal Component #}
Uninstall Protocol Handler

To remove the Moonlight protocol handler from this computer, follow these steps:

Automatic Removal (Recommended)

Download and run this registry file to remove the moonlight:// protocol handler.

Download moonlight-handler-uninstall.reg
Manual Removal

Alternatively, you can manually remove the registry keys:

  1. Press Win + R and type regedit
  2. Navigate to HKEY_CURRENT_USER\Software\Classes
  3. Delete the moonlight folder
After uninstalling, you will no longer be able to launch Moonlight streams directly from this dashboard. You can reinstall anytime using the Setup button.
